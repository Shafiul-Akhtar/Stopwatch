# Python Stopwatch UI

This project contains a simple stopwatch application built with Python's built-in Tkinter library.

## Features

- Start, pause, and reset the timer
- Record lap times
- Clean desktop-style interface

## Run it

From the project folder, execute:

```bash
python main.py
```

## Files

- `main.py` – application entry point
- `stopwatch.py` – stopwatch logic and UI

## Notes

Tkinter is included with most Python installations on Windows, macOS, and Linux.
